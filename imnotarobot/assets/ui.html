Уведомления
Держать запущенным
Включено — приложение запускает программу и открывает снова, если её закрыли. Выключено — никогда не запускает её само.
Расширение для браузера
Капчи на открытых страницах решаются сами, без кликов: Chrome и антидетект-браузеры на Chromium.
Папка расширения
Chrome: chrome://extensions → включите «Режим разработчика» → «Загрузить распакованное расширение» → выберите её. В антидетект-браузере (Dolphin Anty, AdsPower, Octo) добавьте её как локальное расширение к профилю.
Ключ доступа
Вставьте его в настройках расширения один раз. Адрес сервера там уже стоит: http://127.0.0.1:8765.
