# Я не робот

[English](README.md) · **Русский**

**Решатель капч для macOS, который сначала пробует бесплатное.** Замена API 2Captcha и RuCaptcha: капчу сначала решает своя модель, потом любая облачная модель на ваш выбор, потом невидимый браузер, а люди за деньги — только если не справился никто. Есть программа в строке меню и MCP-сервер для ИИ-агентов.

![Я не робот: окно и панель в строке меню, демонстрационные цифры](docs/images/hero.png)

## Зачем

- **Любая модель, можно бесплатно.** Ключ любой модели с картинками — GPT, Claude, Gemini, Qwen, DeepSeek, Grok, OpenRouter, посредник или своя модель через Ollama. Лучшая для капч включается сама. С бесплатным ключом или своей моделью большинство капч до платной ступени не доходит.
- **Без правки кода.** Любая программа, которая умеет API 2Captcha или RuCaptcha, работает после смены одного адреса.
- **Лестница, а не одна ставка.** Своя модель → облачная → запасная облачная → браузер → люди. Ступень, которая не уверена, ошиблась или молчит, передаёт капчу следующей.
- **Учится на ошибках.** Отметили ответ неверным — ступень больше не решает эту картинку; ступень, которая часто ошибается на каком-то виде капч, для него пропускается; жалоба на ответ людей уходит сервису, и он возвращает деньги.
- **Всё на виду.** Журнал каждой капчи с картинкой, ответом и путём по ступеням, лимиты денег на день, сравнение моделей.
- **Для агентов.** MCP-сервер: Claude, Cursor и другие агенты решают капчи через программу.

## Быстрый старт

1. Скачайте `ImNotARobot.dmg` из [Releases](https://github.com/zigansh1n/imnotarobot/releases) и перенесите программу в «Программы». В Finder она называется «Я не робот». Подписи Apple пока нет: если macOS не даст открыть, нажмите «Всё равно открыть» в Системных настройках → Конфиденциальность и безопасность. Следующие версии ставятся из самой программы: раз в день она смотрит GitHub и показывает кнопку «Обновить».
2. Вставьте в «Ключи и модели» ключ любой модели с картинками: поставщик определится сам, лучшая для капч модель включится сама. Ключа нет — у Gemini есть бесплатный: [aistudio.google.com/apikey](https://aistudio.google.com/apikey).
3. В своей программе поменяйте адрес сервиса капч на `http://127.0.0.1:8765`, а ключ — на ключ доступа из раздела «Подключение».

По желанию добавьте ключ RuCaptcha или 2Captcha — последней, платной ступенью.

## Как это работает

| Ступень | Решает | Цена | Время |
|---|---|---|---|
| 1. Своя модель (ddddocr, сравнение кусочков) | текст, слайдеры | бесплатно | доли секунды |
| 2. Облачная модель (любая: GPT, Claude, Gemini, Qwen, DeepSeek, Grok, своя) | текст, сетки картинок, клики | бесплатно или копейки | 3–8 с |
| 3. Запасная облачная (другая модель или та же с раздумьями) | то, в чём вторая не уверена | бесплатно или копейки | 10–50 с |
| 4. Браузер (невидимый Chrome) | reCAPTCHA v2/v3, hCaptcha, Turnstile | бесплатно | от 3 с до 2 мин |
| 4а. Ваш браузер по CDP (профиль антидетекта) | слайдер DataDome, Arkose FunCaptcha | бесплатно | 5–60 с |
| 5. RuCaptcha / 2Captcha | всё | платно | 10–60 с |

## Замеры

На нашем наборе и официальных демо-страницах, октябрь 2026. Выборки маленькие; часть с галочками повторите сами: `python -m imnotarobot.demo_bench --runs 10`.

| Капча | Результат |
|---|---|
| Текст, сетки картинок (облачная модель) | 100% |
| Клики на настоящих капчах (облачная модель) | 69–72% из 39 |
| reCAPTCHA v2 на демо Google (браузер) | Google принял 2 из 3, медиана 118 с |
| reCAPTCHA v3, тестовый ключ Turnstile (браузер) | 5 из 5, 3–4 с |
| hCaptcha на демо (браузер) | 5 из 5, медиана 82 с |
| Слайдер DataDome на etsy.com, seloger.com (свой Chrome по CDP) | 2 из 2; блокировка IP распознаётся |
| Arkose FunCaptcha | на живой капче пока не проверен |

## Из кода

Пример на Python, MCP и список видов заданий — в [английском README](README.md#use-from-code): они одинаковые для обоих языков. Старое API (`in.php` / `res.php`) тоже работает.

### DataDome и Arkose в вашем браузере

Обе защиты оценивают браузер и IP больше, чем ответ, а cookie или токен привязаны к этому браузеру. Поэтому решаем
там, где капча появилась: в профиле антидетекта (Dolphin, AdsPower, Multilogin, Octo или Chrome с
`--remote-debugging-port`). Передайте адрес DevTools профиля в `cdpEndpoint`, вкладку выберет `websiteURL`.

```json
{"type": "DataDomeSliderTask", "cdpEndpoint": "http://127.0.0.1:9222", "websiteURL": "https://www.etsy.com/"}
```

Вкладка проходит проверку сама, в ответе ещё `cookie` и `userAgent` (DataDome) или `token` (Arkose). Браузер мы только
подключаем и не закрываем. Если DataDome сразу блокирует IP («Access is temporarily restricted»), не поможет никакой
решатель: ответ так и скажет — смените прокси. Без `cdpEndpoint` задача уходит в RuCaptcha. В MCP это `solve_in_browser`.

## Сервер (Docker)

То же API и MCP на Linux, без окна. Готовый образ для серверов x86 и ARM выходит с каждой версией:

```bash
docker run -d --restart unless-stopped -p 8765:8765 -e GEMINI_API_KEY=... -e CLIENT_KEY=ваш-ключ-доступа \
  -v imnotarobot:/data --name imnotarobot ghcr.io/zigansh1n/imnotarobot
```

Обновить: `docker pull ghcr.io/zigansh1n/imnotarobot`, затем удалить контейнер и запустить ту же команду; ключи и история остаются в томе `imnotarobot`. Собрать самому: `docker build -t imnotarobot .`

`HUMAN_API_KEY` (и `HUMAN_PROVIDER=2captcha`, если нужно) добавляет платную последнюю ступень. Ключи лежат в `/data/secrets.json`, читать его может только сервер.

## Сборка из исходников

```bash
uv venv -p 3.12 .venv && uv pip install -p .venv/bin/python -e ".[test]" pyinstaller
.venv/bin/python -m pytest -q
packaging/build.sh          # собирает ImNotARobot.app в ~/Applications
.venv/bin/python -m imnotarobot --port 8765   # только сервер, без окна
```

Программа говорит на языке системы: русском или английском. Настройки, журнал и ключи лежат в `~/Library/Application Support/captcha-stack` и Связке ключей (служба «Captcha Stack») — у них осталось первое имя проекта, чтобы при переименовании ничего не потерялось.

### Подпись сборки

Без подписи каждая сборка выходит ad hoc: macOS считает её новой программой и после каждой
пересборки снова спрашивает разрешение на фоновую работу (объект входа) и уведомления. Один раз
запустите `packaging/make_cert.sh`: он создаст самоподписанный сертификат «ImNotARobot Local» в
вашей Связке ключей (пароль не нужен), и `build.sh` будет подписывать каждую сборку им — для macOS
это одна и та же программа от сборки к сборке. Если что-то из этого выключено, окно программы
покажет предупреждение с кнопкой в нужный раздел Системных настроек.

`IMNOTAROBOT_SIGN_IDENTITY` задаёт другую подпись; `IMNOTAROBOT_DISTPATH` вместе с
`IMNOTAROBOT_NO_INSTALL=1` собирает в указанную папку без установки в ~/Applications.
